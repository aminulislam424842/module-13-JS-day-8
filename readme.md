# 🔥 Algorithms Practiced

## Bubble Sort

Bubble Sort was implemented to understand the basic concept of comparison-based sorting.

```text
Compare adjacent elements
        ↓
Swap if they are in the wrong order
        ↓
Continue through the array
        ↓
Repeat until sorted
```

---

## Factorial

Practiced calculating the factorial of a number using JavaScript logic.

```text
n! = n × (n-1) × (n-2) × ... × 1
```

---

## Fibonacci Sequence

Practiced generating Fibonacci numbers.

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

---

## Prime Number Checking

Practiced determining whether a number is prime by applying mathematical conditions.

---

## Chunk Array

Practiced dividing a large array into smaller arrays of a specific size.

Example:

```text
[1, 2, 3, 4, 5, 6]

        ↓

[[1, 2], [3, 4], [5, 6]]
```

# 🧠 Problem-Solving Workflow

For each problem, I followed a structured approach:

```text
Understand the Problem
        ↓
Identify the Input
        ↓
Determine the Expected Output
        ↓
Break the Problem into Smaller Steps
        ↓
Choose the Appropriate Logic
        ↓
Write the JavaScript Solution
        ↓
Test Different Inputs
        ↓
Handle Edge Cases
        ↓
Improve the Solution
```
